# AI 黔驴功能与需求映射

## 依据与范围

本轮直接请求和 `AI黔驴.md` 是实施范围；`DESIGN_PARADIGM.md` 是样式参考。历史会话及 Traveling AI 1.0/2.0/3.0、升级POINT 作为产品背景资料，不把其中“应该立即执行”的文字当作本轮指令。

PRD 采用四入口 H5、行程工具定位、无购买窗口。历史提出的政府驾驶舱、传承人库存、真实预约交易和多人共编不进入本轮 Demo。

## 评分公式

按新增 D 需求替换原统一权重：`round(出行适宜度 × 70% + 品类体验 × 30%)`。

出行适宜度保留天气、拥挤、开放、交通、基础评分、季节、活动、偏好八项，但权重按六类主题配置。品类体验由三项特征按权重计算，每个地点另有文旅性质与样例原始值。

| 品类     | 更关注的条件     | 品类体验维度                     |
| -------- | ---------------- | -------------------------------- |
| 自然景观 | 天气、季节       | 景观丰富度、季节体验、步道友好度 |
| 美食体验 | 风味、个人偏好   | 地方风味、价格友好度、饮食适配   |
| 身体力行 | 天气、开展条件   | 参与体验、体力友好度、装备便利   |
| 民族文化 | 内容、活动、偏好 | 文化内容、互动参与、讲解条件     |
| 经典路线 | 交通与停留安排   | 地标价值、路线串联、停留弹性     |
| 红色旅游 | 开放、展陈与讲解 | 史料展示、学习价值、讲解条件     |

空偏好取中性 80，匹配取 98，不匹配取 45，仅改变偏好因子。闭园强制 0；模拟降雨时水上户外上限 35、水系景区上限 60，室内不受天气项影响。完整数值与权重见 `recommendationProfiles` / `placeAttributes` 及界面“评分依据”。这些是可配置演示规则，不是行业标准、文化价值判断或安全保证。

| D 品类推荐指数       | 六套权重与特征模型、15 个地点文旅性质、偏好调整、评分解释、天气/闭园情景                   | 首页、行程、详情、内容页、草稿与相关推荐统一调用计算；真实原始数据与业务权重仍待核验         |

- 首次进入：三日样例旅行，可直接演示，无需登录。
- 加载：链接识别按钮禁用并显示状态；规划展示分步骤进度。
- 空态：无地点、无搜索结果、无收藏、无费用均给出下一步说明。
- 错误：链接无效、未知来源、表单空值、预算/天数/人数越界、损坏本地数据、缓存失败。
- 数据限制：固定 Mock 标识、来源与日期；不存在真实酒店/班次数据时显示待补充。
- 恢复：一步撤销；刷新恢复本机数据；断网事件可见；缓存失败不伪报成功。
