## 本地估算规则

- 近似距离：地点样例坐标的球面距离 × 1.45，不是地图道路距离。地图链接同样传递这些近似点位，界面要求用户核对正确的门店和入口。
- 驾车时间：市内按22 km/h、长距离按50 km/h，加5分钟上车缓冲；打车费用为假定每公里费率范围，不是报价。按每车最多4位乘客估算总费用，自驾油费、停车、高速另计。
- 步行：只给同区域且估算不超过5 km的候选，按4 km/h计算。它不证明两点之间有可通行步道。
- 公交：仅为已有资料的候选显示线路结构；其他路段只提供百度地图查询，不填写虚构的线路号、站点、时间或费用。
- 铁路：仅贵阳与黔东南之间提供可编辑的枢纽接驳参考，含进站/候车缓冲。不生成指定车次。
- 每种可应用方案的总时长等于其步骤之和。路段选择绑定前一个 TripItem ID，调序/删除后不会把上一段选项错误套用到另一段。
- 只有跨区域的日期会计入上日尾站接续。住宿没有精确地址，酒店绕行、首次抵达和最后返程仍需另查，不包含在地点连线中。

## 后续接入

当前前端支持通过 `VITE_BAIDU_MAP_AK` 配置百度 JSAPI 4.0 浏览器端 AK；该 AK 应在百度控制台限制域名白名单，不能作为服务端 Web Service 密钥使用。若需要实时路线结果，应另配受保护的服务端 Key 并通过服务端适配器调用路径规划服务。适配器应验证坐标、目标城市与日期，处理未找到路线、超时、限流、跨城公交和上游错误，保留“真实接口返回 / 资料整理 / 本地估算”三种来源。
