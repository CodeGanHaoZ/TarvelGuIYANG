# DESIGN_PARADIGM 落地

遵循用户给定范式的暖色渐变、可见状态、大圆角、卡片主副信息、可切换语义主题。参考图只用于布局与视觉语言，不复制其品牌资产和地图截图。

## 色彩与版式

- 默认 Coral：暖白工作区、珊瑚渐变创建页与首页、深珊瑚按钮，配生态绿评分卡。
- Ocean / Forest / Lavender / Mono 由 `data-theme` 与共享 CSS 变量切换，页面内容不重建。
- PC：224px 导航侧栏；行程页时间轴和地图分栏。中等桌面缩小侧栏和组件密度。
- H5：760px 以下使用四项固定底栏；地图移至时间轴上方，地图点位可弹出详情；对话框适配 92dvh，内容可滚动。
- 图标统一从 travel-icons.tsx 提供，默认线性；加粗与 Emoji 为同一语义映射的变体。
- 首页社交卡片宽度为原版 1/2，封面改为 3:4 竖图；下方仅保留两行标题、作者/互动数、收藏与规划入口。全区不分平台，Mock 说明集中在副标题与内容页。保留横向滑动，不显示顶部角标。
- 六类主题为固定 3 列 × 2 行图片网格；图片上用深色渐变与白字保持识别，手机仍显示完整六项，不设置横向滚动。
- 六类主题使用“山水奇观 / 舌尖黔味 / 多彩民族 / 古镇遗韵 / 野趣户外 / 红色征程”，配纯观光、美食、文化体验、历史人文、身体力行、历史缅怀副标题。热门内容在卡片正文标注类别，不添加平台筛选或封面角标；全文与快捷阅读展示分类边界。

## 交互反馈

选中卡片、地图点位、日期、偏好、主题均有形状/文字/描边反馈，不只依赖颜色。加载、空态、错误、完成和本机保存提示分别可见。

Button/Input/Progress/Dialog 复用 shadcn 与 Base UI，保留对话框焦点管理和 Escape；地图 SVG 点位可通过 Tab、Enter/Space 操作。移动排序提供上下按钮。动画尊重 `prefers-reduced-motion`。

## 视觉资产

本地照片在 `public/images`，来源见 README 与应用内说明；未有照片的地点使用类别图标，避免拿别处照片冒充。品牌社交预览 `public/og.png` 为独立 AI 生成画面，不作为真实地点摄影。

真实上线前需执行浏览器截图/对比度/手机触摸与无障碍审计，并替换为已获授权的摄影素材。
